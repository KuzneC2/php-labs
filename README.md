## О проекте

В данном репозитории представлены пять лабораторных работ по дисциплине «Серверная разработка».

Все работы объединены в один PHP-проект с общей главной страницей, с которой можно перейти к каждой лабораторной.

**Используемые технологии:**
- PHP 8
- MySQL / MariaDB
- HTML5, CSS3
- Apache (XAMPP)
- PDO для работы с базой данных
- phpMyAdmin

## Лабораторная работа №1 — Форма обратной связи

**Задание:** создать сайт из двух страниц.

**Первая страница:**
- Форма обратной связи с полями имени, email, типа обращения и текста сообщения.
- Выбор варианта ответа: SMS или email.
- Отправка формы методом POST на `https://httpbin.org/post`.
- Ссылка для перехода на вторую страницу.

**Вторая страница:**
- Получение HTTP-заголовков с помощью функции `get_headers()`.
- Вывод результата в `textarea`.

На страницах предусмотрены шапка с логотипом МосПолитеха, название работы и подвал с заданием для самостоятельной работы.

**Расположение:** `lab1/`

## Лабораторная работа №2 — Записная книжка

**Задание:** разработать веб-приложение для хранения и управления контактами с использованием базы данных.

Каждый контакт содержит следующие данные:
- Фамилия, имя, отчество.
- Пол и дата рождения.
- Телефон и адрес.
- Email и комментарий.

**Реализованные возможности:**
- Просмотр контактов в таблице.
- Добавление новых записей с валидацией.
- Редактирование существующих записей.
- Удаление контактов.
- Сортировка по порядку добавления, фамилии и дате рождения.
- Пагинация — не более 10 контактов на странице.

Основная работа сайта осуществляется через `index.php`. Для отдельных операций используются программные модули:

| Файл | Назначение |
|---|---|
| `index.php` | Главная точка входа |
| `menu.php` | Навигационное меню |
| `viewer.php` | Просмотр, сортировка и пагинация |
| `add.php` | Добавление контактов |
| `edit.php` | Редактирование контактов |
| `delete.php` | Удаление контактов |
| `db.php` | Подключение к базе данных |

Основные кнопки меню имеют синий цвет, активная кнопка выделяется красным.

**Расположение:** `lab2/`

## Лабораторная работа №3 — Контроллеры и маршрутизация

**Задание:** создать метод `sayBye(string $name)` в контроллере и добавить маршрут `/bye/$name`.

При переходе по адресу `/bye/Dima` должно выводиться сообщение:

**Пока, Dima**

В проекте также реализован метод приветствия `sayHello(string $name)`.

Для обработки маршрутов используется PHP и конфигурационный файл `.htaccess`.

**Расположение:** `blog/`

## Лабораторная работа №4 — Шаблоны и динамические заголовки

**Задание:** реализовать возможность передачи заголовка страницы `title` через переменную PHP-шаблона.

Если заголовок не передан, должно использоваться значение по умолчанию — «Мой блог».

Для маршрута `/hello/username` необходимо установить заголовок «Страница приветствия».

**Реализованные возможности:**
- Общий HTML-шаблон для страниц блога.
- Динамическое формирование тега `<title>`.
- Индивидуальные заголовки страниц.
- Отдельная страница для демонстрации значения по умолчанию.

**Расположение:** `blog/templates/`

## Лабораторная работа №5 — Статьи и авторы

**Задание:** в методе `ArticlesController::show()` после получения статьи выполнить дополнительный запрос к таблице `users` и вывести `nickname` автора в шаблоне.

Для выполнения работы используются две связанные таблицы базы данных:

- `users` — информация о пользователях.
- `articles` — статьи с указанием идентификатора автора.

**Реализованные возможности:**
- Получение списка статей из MySQL.
- Просмотр отдельной статьи.
- Получение автора отдельным SQL-запросом.
- Вывод никнейма автора в шаблоне.
- Автоматическое формирование заголовка страницы на основе названия статьи.

**Расположение:** `blog/controllers/ArticlesController.php`

## Локальный запуск

Для запуска проекта необходимы Apache, PHP и MySQL/MariaDB.

1. Установить и запустить XAMPP.
2. Скопировать папку `php-labs` в каталог `htdocs`.
3. Запустить службы Apache и MySQL.
4. Создать в phpMyAdmin базу данных `php_labs`.
5. Создать необходимые таблицы `contacts`, `users` и `articles` и добавить тестовые данные.
6. Настроить локальное подключение к базе данных.
7. Открыть проект в браузере по адресу:

`http://127.0.0.1/php-labs/`

Для работы маршрутов блога требуется поддержка Apache `mod_rewrite` и `.htaccess`.
